
# Setup

In this post, I will be prepare for my study in Amazon Web Services. 

## Create AWS Account

To start working with **Amazon Web Services (AWS)**, we should start by creating an account. I will be using a free account, and this is apparantly enough for studying purposes. You need a card information in order to create an account. 

[AWS Website](https://aws.amazon.com/console/)

Go to **Create Account**, and follow the instructions. 
![[image.png]]

> [!NOTE] Billing Alert & MFA
> If you are scared of unexpected large bills (which is very unlikely to happen), set up the *billing alert* and *Multi-Factor Authentication* at `Accounts` and `Security credentials` tabs.
